# AutoDL 助手

本地运行的中文 AutoDL 工作台，提供 GPU 库存监测、抢卡任务、实例管理、账单查询和消息提醒。

[下载与安装](#installation) · [开始使用](#first-use) · [通知设置](#notifications) · [软件更新](#updates) · [常见问题](#faq)

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 监控室 | 查看 GPU 库存、型号与地区分布、空闲趋势和主机明细，支持自动跟踪与筛选 |
| 抢卡控制台 | 创建新租、已有实例开机或同地区克隆任务，支持仅提醒、自动执行、暂停与恢复 |
| 我的实例 | 搜索实例，查看配置与运行状态，选择监控目标或前往官网管理 |
| 账单 | 查看余额、消费走势和近期流水 |
| 消息与通知 | 查看任务消息，通过桌面提醒、Webhook 或 AutoDL 微信接收通知 |
| AI 选卡 | 根据需求辅助选择 GPU 和运行环境，确认后应用到任务配置 |

适用于 AutoDL **普通容器实例**，不支持 `pro-...` 容器实例 Pro。可选地区包括北京 B、西北 B、重庆 A、内蒙 B、北京 A、佛山，使用官方公共基础镜像。

<a id="installation"></a>
## 下载与安装

**以下五种方式任选一种。希望像普通软件一样使用，推荐 EXE 安装包；希望下载文件较小，可选择单文件在线安装。**

| 方式 | 使用界面 | 环境准备 |
| --- | --- | --- |
| [1. EXE 安装包](#method-1) | 独立桌面窗口 | 内置运行环境，安装后使用 |
| [2. 便携 ZIP](#method-2) | 独立桌面窗口 | 内置运行环境，解压后使用 |
| [3. 源码 ZIP](#method-3) | 本机浏览器网页 | 首次启动自动准备环境 |
| [4. 单文件在线安装](#method-4) | 本机浏览器网页 | 自动下载程序与所需环境 |
| [5. PowerShell 安装](#method-5) | 本机浏览器网页 | 通过命令安装，可指定目录 |

- **系统：**Windows 10/11 x64。连接 AutoDL 需要联网，本机无需独立显卡。
- **环境：**上述方式均无需提前安装 Node.js、npm 或 Git。网页版会按需下载运行环境和浏览器组件。
- **下载版本：**本文链接对应 [v2.0.1 正式版](https://github.com/Starry-cz/autodl-assistant/releases/tag/v2.0.1)。

<a id="method-1"></a>
### 1. EXE 安装包

1. [下载桌面安装包](https://github.com/Starry-cz/autodl-assistant/releases/download/v2.0.1/autodl-assistant-desktop-2.0.1-setup-x64.exe)。文件名以 **setup-x64.exe** 结尾。
2. 双击 EXE，等待安装完成。程序安装到当前 Windows 用户，无需管理员权限。
3. 打开桌面或开始菜单中的 **AutoDL助手桌面版**，按[开始使用](#first-use)连接账号。
4. **以后启动：**打开 **AutoDL助手桌面版** 快捷方式。
5. **完全退出：**右键系统托盘中的助手图标，选择 **停止并退出**。点击窗口右上角 **×** 会收进托盘，后台任务继续运行。

安装包尚未进行 Windows 代码签名，系统可能显示“未知发布者”。请从本仓库发布页下载，无需关闭系统防护。

<a id="method-2"></a>
### 2. 便携 ZIP

1. [下载完整便携包](https://github.com/Starry-cz/autodl-assistant/releases/download/v2.0.1/autodl-assistant-desktop-2.0.1-win-x64.zip)。文件名以 **win-x64.zip** 结尾。
2. 右键 ZIP，选择 **全部解压**，保存到有写入权限的固定文件夹。
3. 打开解压后的文件夹，双击 **AutoDL Assistant.exe**，按[开始使用](#first-use)连接账号。
4. **以后启动：**打开该文件夹中的 **AutoDL Assistant.exe**，也可为它创建桌面快捷方式。
5. **完全退出：**右键系统托盘中的助手图标，选择 **停止并退出**。

请保留解压后的全部文件，不要在压缩包内运行或单独移动 EXE。账号与任务数据保存在本机 AppData，不随便携文件夹移动。

<a id="method-3"></a>
### 3. 源码 ZIP

1. [下载完整源码包](https://github.com/Starry-cz/autodl-assistant/releases/download/v2.0.1/autodl-assistant-v2.0.1.zip)。
2. 右键 ZIP，选择 **全部解压**，保存到有写入权限的固定目录，例如 `D:\AutoDL助手`。
3. 打开项目文件夹，找到 **启动抢卡助手.cmd**；同一层应有 `package.json`、`public`、`src` 和 `scripts`。
4. 双击 **启动抢卡助手.cmd**。保持联网，等待环境准备完成并显示“启动成功”。
5. 浏览器会打开 [http://127.0.0.1:8787](http://127.0.0.1:8787)，按[开始使用](#first-use)连接账号。如未自动打开，可手动输入该地址。
6. **以后启动：**双击同一目录中的 **启动抢卡助手.cmd**，也可为它创建快捷方式。
7. **完全退出：**双击同一目录中的 **停止抢卡助手.cmd**，等待停止完成。关闭网页后后台仍会运行。

首次启动会检查 Node.js 和浏览器，缺少时自动下载；准备好的环境会在后续启动时复用。请完整解压项目后运行。

<a id="method-4"></a>
### 4. 单文件在线安装

1. [下载在线安装文件](https://github.com/Starry-cz/autodl-assistant/releases/download/v2.0.1/autodl-assistant-setup.cmd)：**autodl-assistant-setup.cmd**。
2. 双击该文件并保持联网，等待程序与运行环境下载完成。
3. 默认安装到 `%LOCALAPPDATA%\AutoDL-Assistant`。将此路径粘贴到资源管理器地址栏即可打开安装目录。
4. 出现“安装和启动完成”后，浏览器会打开助手页面，按[开始使用](#first-use)连接账号。
5. **以后启动：**使用桌面的 **AutoDL助手** 快捷方式，或安装目录中的 **启动抢卡助手.cmd**。
6. **完全退出：**双击安装目录中的 **停止抢卡助手.cmd**。

如未生成快捷方式，请直接从安装目录启动。需要指定安装位置时，使用下面的 PowerShell 安装方式。

<a id="method-5"></a>
### 5. PowerShell 安装

1. 按 **Win + R**，输入 `powershell`，按回车。使用普通权限窗口即可。
2. 复制下面的命令到 PowerShell，按回车下载安装脚本：

   ```powershell
   Invoke-WebRequest -UseBasicParsing -Uri "https://raw.githubusercontent.com/Starry-cz/autodl-assistant/v2.0.1/install.ps1" -OutFile "$env:TEMP\install-autodl.ps1"
   ```

3. 下载完成后，执行第二条命令：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-autodl.ps1"
   ```

4. 等待“安装和启动完成”。程序默认安装到 `%LOCALAPPDATA%\AutoDL-Assistant`，浏览器会打开助手页面，按[开始使用](#first-use)连接账号。
5. **以后启动：**使用桌面的 **AutoDL助手** 快捷方式，或安装目录中的 **启动抢卡助手.cmd**。
6. **完全退出：**双击安装目录中的 **停止抢卡助手.cmd**。

如需指定安装目录，将第 3 步替换为以下命令。示例使用 D 盘，请按电脑上的实际路径修改：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-autodl.ps1" -InstallDir "D:\AutoDL助手"
```

## 开始使用

### 连接 AutoDL 账号

1. 点击左下角头像 → **账号设置** → **打开登录**。
2. 在助手打开的 AutoDL 官网窗口中完成登录，密码和验证码均在官网填写。
3. 助手核验成功后会同步实例、账单和 GPU 目录。如仍显示未连接，点击 **检查登录状态**；需要重新同步时，点击 **同步账号内容**。

### 查看 GPU 库存

1. 点击 **返回工作台**，打开 **监控室**。
2. 选择刷新间隔，开始或暂停自动跟踪。
3. 点击型号、地区或热力图格子，筛选下方主机明细。点击 **用于抢卡** 可将条件填入任务配置。

### 创建抢卡任务

进入 **抢卡控制台**，按需求选择任务模式：

| 模式 | 配置内容 | 自动执行时的行为 |
| --- | --- | --- |
| 新租服务器 | 地区、GPU 型号与卡数；同步镜像后选择框架、版本、Python 和 CUDA | 创建新实例并开机 |
| 已有实例开机 | 选择已同步的目标实例；无卡运行的实例需先在官网关机 | 等待原主机有空卡后开机，沿用原实例配置和计费方式 |
| 迁移克隆（同地区） | 已关机源实例、目标 GPU、是否复制数据盘 | 在源实例同地区克隆并开机，保留原实例 |

1. 填写对应配置，选择 **仅提醒** 或 **自动执行**。
2. 设置检查间隔和最长监测时间。仅提醒模式在发现资源后通知并停止；自动执行需勾选费用授权。
3. 启动任务，在右侧队列查看状态、检查次数和倒计时。
4. 打开 **详情与日志** 查看采样、导出日志，或暂停、恢复、停止任务。遇到待核对状态时，按页面提示处理。

新租和克隆按提交时的 AutoDL 报价计费，费用预览不锁价。克隆的数据复制有单独的进度，GPU 开机后仍需确认复制状态。

### 实例、账单与设置

- **我的实例：**查看实例配置和运行状态，设置监控目标或前往官网管理。
- **账单：**点击左下角头像 → **账单**，查看余额、消费走势和流水。
- **设置中心：**点击左下角头像 → **账号设置**，可切换账号、通知、账单和软件更新；点击 **返回工作台** 继续使用业务功能。
- **AI 选卡：**在工作台按需使用，确认建议后再应用配置。

<a id="notifications"></a>
## 通知设置

站内消息始终开启。其他提醒方式可按需配置：

| 渠道 | 准备内容 |
| --- | --- |
| 桌面提醒 | 点击页面右上角 **开启桌面提醒**，按提示允许通知 |
| AutoDL 微信 | 在 AutoDL 绑定微信，并获取账号的开发者 Token |
| Webhook | 准备支持本程序消息格式的 HTTPS 接收地址；按接收服务要求填写 Bearer Token |

**配置与测试微信、Webhook：**

1. 点击左下角头像 → **账号设置** → **通知**。
2. 启用需要的渠道并填写配置，点击 **保存通知设置**。
3. 点击对应渠道的 **发送测试通知**，查看按钮下方的结果或失败原因。
4. 微信渠道显示发送成功后，在手机微信确认收到。若失败，按提示检查 Token、微信绑定、接收地址或网络；限速时等待页面提示的时间后再试。

配置有未保存修改时，测试按钮不可用。微信测试与任务通知共用发送限额。

<details>
<summary>Webhook 接收格式</summary>

以 JSON POST 发送 `id`、`event`、`title`、`name`、`content`、`taskId` 和 `timestamp`，请求包含 `Idempotency-Key`。测试消息的 `event` 为 `test`、`taskId` 为 `null`，接收服务需支持此类型。

</details>

<a id="updates"></a>
## 软件更新

1. 点击左下角头像 → **软件更新**，查看当前版本和最新正式版本，也可点击 **检查更新**。
2. 出现新版本提示后，查看更新说明，点击 **更新并重启**。
3. 等待更新完成，网页自动刷新，桌面窗口重新打开。以后继续使用原快捷方式或启动文件即可。

更新保留登录资料、任务记录、配置和日志。暂停任务保持暂停；会话过期或任务需要核对时，按页面提示处理。更新后可在任务队列确认运行状态。

任务正在提交或核对时，请等待操作完成再更新。下载失败可按页面提示重试。需要手动安装时，先停止任务并完全退出程序，再安装发布页中的 EXE；网页版可运行在线安装脚本，并用 `-InstallDir` 指定原安装目录。

<a id="data"></a>
## 运行与数据保存

| 使用方式 | 首次运行的默认数据位置 | 完全退出方式 |
| --- | --- | --- |
| EXE 安装版、便携版 | `%APPDATA%\AutoDL Assistant Desktop\runtime` | 托盘菜单 → **停止并退出** |
| 源码网页版 | 项目目录中的 `.runtime` | **停止抢卡助手.cmd** |
| 在线安装网页版 | `%LOCALAPPDATA%\AutoDL-Assistant\.runtime`；自定义安装时位于对应目录 | **停止抢卡助手.cmd** |

网页版在同一 Windows 用户、默认端口下沿用已登记的数据目录，重新解压或自动更新后，数据位置可能仍在原安装目录。请保留完整安装目录及其中的数据文件。

- **持续监测：**电脑需保持联网和唤醒。关闭桌面窗口或网页后，后台抢卡任务仍可继续；完全退出程序会停止本地监测。
- **云端费用：**停止任务或退出助手不会关闭 AutoDL 云端实例。请到官网管理关机与释放，扩容数据盘在关机后仍可能计费。
- **账号数据：**同一 Windows 用户的安装版与便携版共用桌面数据；桌面与网页版数据独立。换电脑后需重新登录，本地历史不会自动同步。
- **备份与隐私：**完全退出程序后可备份数据目录。其中包含登录资料，请勿上传或分享；加密保存的可选凭据由当前 Windows 用户保护。
- **退出账号：**头像菜单中的 **退出 AutoDL** 用于退出账号，完全退出程序请使用上表中的方式。

<details>
<summary>看板刷新与后台通知</summary>

监控室的自动跟踪在查看该页面时运行。网页版切换到后台标签或关闭网页后，看板会暂停刷新；桌面版停留在监控室并收进托盘时仍可跟踪。抢卡任务按各自的检查间隔在后台运行。

关闭网页版后，浏览器桌面提醒不再弹出，站内消息仍会保留；已配置的 Webhook 和微信通知由后台发送。

</details>

<a id="faq"></a>
## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 第一次启动很慢 | 网页版首次需要下载环境与依赖。保持联网，等待窗口中的步骤完成；需能访问 GitHub、nodejs.org、npm 和浏览器下载服务。 |
| ZIP 中找不到 EXE | 便携包运行 `AutoDL Assistant.exe`；源码包运行 `启动抢卡助手.cmd`。请按上方对应链接下载。 |
| EXE 提示缺少文件 | 将便携包完整解压到一个文件夹，保留所有文件后再运行。 |
| 网页没有自动打开 | 确认启动窗口显示成功后，在浏览器打开 `http://127.0.0.1:8787`。 |
| 关闭后找不到桌面窗口 | 查看系统托盘及隐藏图标，点击助手图标，或再次打开快捷方式。 |
| 官网已登录，助手仍未连接 | 在助手的 **账号设置** 中打开专用登录窗口，完成登录后点击 **检查登录状态**。 |
| 库存或账单显示“—” | 连接账号后重新同步。“—”表示尚未取得数据。 |
| 提示端口被占用 | 从正在运行的网页版安装目录执行 **停止抢卡助手.cmd**，再启动所需版本。 |
| 在线安装提示目录不为空 | 选择空目录，或确认路径属于现有 AutoDL 助手安装；不要删除账号数据。 |
| 测试通知没有收到 | 查看通知页面的发送结果，核对微信绑定或 Webhook 配置，再到接收端确认消息。 |

## 开发

<details>
<summary>项目结构、开发运行与打包</summary>

| 路径 | 内容 |
| --- | --- |
| `public/` | 网页界面 |
| `src/server.mjs` | 本地 HTTP 服务 |
| `src/engine.mjs` | 任务调度与执行 |
| `src/adapters/` | AutoDL 浏览器会话与页面交互 |
| `src/store.mjs`、`src/credentials.mjs` | 数据存储与凭据保护 |
| `desktop/` | Electron 窗口、托盘及打包配置 |
| `scripts/` | 环境准备、启动、停止和构建脚本 |
| `tests/` | 自动测试 |

安装 Node.js 22.12+（含 npm），在项目根目录打开 PowerShell：

```powershell
npm.cmd ci
npm.cmd run browser:install
npm.cmd start
```

打开 `http://127.0.0.1:8787`。在启动终端按 Ctrl+C，或另开终端执行 `npm.cmd run stop` 停止服务。

运行检查：

```powershell
npm.cmd test
npm.cmd run check
npm.cmd run test:workspace-ui
npm.cmd run test:market-ui
```

桌面调试使用独立数据目录：

```powershell
$env:AUTODL_DESKTOP_DATA_DIR = Join-Path $env:TEMP 'AutoDL-Assistant-Dev'
npm.cmd run desktop:dev
```

Windows x64 构建命令为 `npm.cmd run desktop:build`，安装包与便携包生成在 `output/desktop`。构建时需联网下载依赖和配套浏览器。

</details>
