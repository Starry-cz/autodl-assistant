# AutoDL 助手

v1.0.0 · 本地运行的中文 AutoDL 工作台，集中查看 GPU 库存、管理抢卡任务、浏览实例与账单。

## 功能

- **监控室**：库存统计、型号与地区分布、趋势和热力图，支持自动跟踪、暂停及主机明细筛选。
- **抢卡控制台**：支持新租服务器、已有实例开机和同地区克隆，可选择仅提醒或自动执行。
- **我的实例**：搜索与状态筛选、配置详情、监控目标选择，以及官网管理入口。
- **账单**：消费趋势、近期流水、余额、代金券及冻结金额。
- **消息与通知**：任务消息、桌面提醒、可选 Webhook 和 AutoDL 微信通知。
- **AI 选卡**：根据项目需求辅助选择 GPU 与运行环境，可选配置模型服务。

## 安装与启动

需要 **Windows 10/11、Node.js 22 或更新版本，以及 Edge / Chrome**。本机不需要 GPU。

1. 下载源码包并完整解压到固定目录。
2. 安装 Node.js，在 PowerShell 运行 `node --version`，确认版本不低于 22。
3. 双击 **启动抢卡助手.cmd**。首次启动会联网安装依赖，随后启动后台并打开 [本地页面](http://127.0.0.1:8787)。
4. 若提示没有可用浏览器，在项目目录执行 `npm.cmd run browser:install`，完成后重新启动。

也可以在项目目录手动启动：

```powershell
npm.cmd ci
npm.cmd start
```

手动启动在前台运行，按 Ctrl+C 停止；双击启动使用隐藏后台。

## 开始使用

1. 点击左下角头像进入“账号”（手机在右上角），点击“打开登录”，在 AutoDL 官网窗口完成登录。
2. 登录确认后窗口转入后台，助手同步账号、实例、账单与 GPU 目录。需要人工验证或登录失效时，按账号页提示处理。
3. 在“抢卡控制台”选择任务模式并填写配置。
4. 选择“仅提醒”或自动执行，设置检查间隔和最长监测时间。自动执行需勾选费用授权后启动。
5. 在任务卡查看状态、检查次数与倒计时，通过“详情与日志”查看采样、导出日志或管理任务。

| 模式 | 需要选择的内容 | 发现资源后 |
| --- | --- | --- |
| 新租服务器 | 地区、GPU 型号与数量、官方基础镜像 | 按配置创建并开机 |
| 已有实例开机 | 已同步的目标实例 | 等待原主机有 GPU 后开机，沿用原配置与计费方式 |
| 同地区克隆 | 已关机源实例、目标 GPU、是否复制数据盘 | 在同地区克隆并开机，保留源实例 |

以上操作仅在选择自动执行并授权后进行；**仅提醒**发现符合条件的资源后通知并停止，不创建或开机。AI Key、开发者 Token 余额保护和外部通知均为可选功能。

监控室点击型号、地区或热力格可筛选主机；主机行“用于抢卡”只填入型号与地区，不锁定该主机，仍需核对并提交任务。

## 使用说明

- 支持普通容器实例，不支持 `pro-...` 容器实例 Pro。当前可选地区为北京 B、西北 B、重庆 A、内蒙 B、北京 A、佛山，使用官方公共基础镜像。
- 库存、实例指标与账单均为同步时的快照；未读取到的数据不会视作零，分页未完整时会提示。抢卡结果取决于库存、网络和平台响应。
- 新租与克隆按 AutoDL 提交时的报价执行，预览不锁价；扩容数据盘在关机后仍可能计费。
- 克隆开机与数据盘复制分别核验，开机不等于数据复制完成。取消复制数据盘时，只克隆系统盘。
- 同一实例只保留一个未结束的开机任务；提交结果不明确时先核对，不重复下单。
- 切换账号会停止原账号的后续任务并切换实例、账单及消息范围；预算保护与通知凭据需按账号重新配置。

## 停止与本地数据

关闭助手网页不会停止任务，电脑需要保持联网和唤醒。双击 **停止抢卡助手.cmd**，或执行以下命令停止后台：

```powershell
npm.cmd run stop
```

**停止监测或本地后台不会关闭云端实例。** 使用结束后，请到 AutoDL 控制台关机。

任务、日志和登录资料保存在 `.runtime/`，请妥善保留，不要上传或分享。桌面提醒需要助手页面保持打开。本项目为独立工具，与 AutoDL 官方无隶属关系。
