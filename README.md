# AutoDL 助手

v1.1.0 · 本地运行的中文 AutoDL 工作台，集中查看 GPU 库存、管理抢卡任务、浏览实例与账单。

## 下载安装（推荐桌面版）

适用于 **Windows 10/11 x64**。安装包自带 Electron、Node.js、Playwright 和 Chromium，**无需预装 Node.js、npm 或 Git，也无需在首次启动时联网下载运行环境**。登录 AutoDL、刷新库存和执行任务仍需要联网，不需要本机 GPU。

| 下载方式 | 操作 |
| --- | --- |
| [桌面安装包 Setup.exe](https://github.com/Starry-cz/autodl-assistant/releases/download/v1.1.0/autodl-assistant-desktop-1.1.0-setup-x64.exe)（推荐） | 下载后双击，按提示完成当前用户安装。以后打开桌面的 **AutoDL助手桌面版**。 |
| [完整便携 ZIP](https://github.com/Starry-cz/autodl-assistant/releases/download/v1.1.0/autodl-assistant-desktop-1.1.0-win-x64.zip) | 右键“全部解压”，进入文件夹运行 **AutoDL Assistant.exe**。保留同目录的全部文件。 |

桌面安装不需要管理员权限。便携 ZIP 包含完整程序，**不是 GitHub 的 Source code 源码 ZIP**；不要在压缩包内运行，也不要只取出 EXE。

当前 Windows 安装包尚未进行代码签名，安装时可能显示“未知发布者”或系统提示。请核对下载来自本仓库的发布页，无需关闭系统防护。

ARM64 暂用下方的 v1.0.2 网页入口；当前未提供 ARM64 桌面包，也未在 ARM64 实机验证。

## 开始使用

1. 打开桌面程序，点击左下角头像进入“账号”，选择“打开登录”，在 AutoDL 官网窗口完成登录。
2. 登录确认后，登录窗口转入后台；回到助手查看已同步的账号、实例、账单和 GPU 目录。
3. 在“抢卡控制台”选择任务模式，填写配置、检查间隔和最长监测时间。
4. 选择“仅提醒”或自动执行。自动执行需勾选费用授权后启动。
5. 在任务卡查看状态、检查次数与倒计时；“详情与日志”可查看采样、导出日志及管理任务。

| 模式 | 需要选择的内容 | 自动执行时 |
| --- | --- | --- |
| 新租服务器 | 地区、GPU 型号与数量、官方基础镜像 | 按配置创建并开机 |
| 已有实例开机 | 已同步的目标实例 | 等待原主机有 GPU 后开机，沿用原配置与计费方式 |
| 同地区克隆 | 已关机源实例、目标 GPU、是否复制数据盘 | 在同地区克隆并开机，保留源实例 |

**仅提醒**发现符合条件的资源后通知并停止，不创建或开机。AI Key、开发者 Token 余额保护和外部通知均为可选功能。

## 功能

- **监控室**：库存统计、型号与地区分布、趋势和热力图，支持自动跟踪、暂停及主机明细筛选。点击型号、地区或热力格即可筛选；“用于抢卡”只填入型号与地区，仍需核对并提交任务。
- **抢卡控制台**：新租、开机和克隆任务，支持仅提醒或自动执行、暂停、恢复及日志导出。
- **我的实例**：搜索与状态筛选、配置详情、监控目标选择，以及官网管理入口。
- **账单**：消费趋势、近期流水、余额、代金券及冻结金额。
- **消息与通知**：任务消息、桌面提醒、可选 Webhook 和 AutoDL 微信通知。
- **AI 选卡**：根据项目需求辅助选择 GPU 与运行环境，可选配置模型服务。

## 关闭、退出与升级

- 点击窗口右上角 **×** 会隐藏到系统托盘，任务继续运行。从托盘菜单可重新打开窗口。
- 要结束本地程序，请在系统托盘菜单选择 **停止并退出**。程序会等待当前操作收尾；电脑需保持联网和唤醒才能持续监测。
- **退出程序或停止监测不会关闭云端实例。** 使用结束后，请到 AutoDL 控制台关机。
- 以后安装新版桌面包会继续使用原来的本地数据。升级前先从托盘退出；便携版应将新版完整解压到新文件夹，再打开新程序。
- 重新打开后先检查登录和任务状态，需要时重新登录并恢复任务，不要将启动程序等同于恢复抢卡。

桌面版数据保存在 `%APPDATA%\AutoDL Assistant Desktop\runtime`，可将这行路径粘贴到资源管理器地址栏打开。**便携版也使用当前电脑的 AppData，数据不会随 EXE 或 U 盘一起移动。** 该目录包含任务、日志和登录资料，请勿上传或分享。

**从旧网页版首次使用桌面版，需要重新登录。** 桌面版使用独立数据目录，不会自动导入旧项目的 `.runtime`；AI、通知等可选设置按需重新配置。换电脑后也需重新登录，不要复制登录资料或凭据目录。

## 使用范围

- 支持普通容器实例，不支持 `pro-...` 容器实例 Pro。当前可选地区为北京 B、西北 B、重庆 A、内蒙 B、北京 A、佛山，使用官方公共基础镜像。
- 库存、实例指标与账单均为同步时的快照；未读取到的数据不会视作零，分页未完整时会提示。抢卡结果取决于库存、网络和平台响应。
- 新租与克隆按 AutoDL 提交时的报价执行，预览不锁价；扩容数据盘在关机后仍可能计费。
- 克隆开机与数据盘复制分别核验，开机不等于数据复制完成。取消复制数据盘时，只克隆系统盘。
- 同一实例只保留一个未结束的开机任务；提交结果不明确时先核对，不重复下单。
- 切换账号会停止原账号的后续任务并切换实例、账单及消息范围；预算保护与通知凭据需按账号重新配置。

## 保留的网页入口：v1.0.2

旧网页版继续提供，适用于 Windows 10/11 x64 / ARM64；ARM64 路径尚未实机验证。**此方式首次运行需要联网下载运行环境与依赖**，与上方自带环境的桌面包不同。

- [单文件安装启动器](https://github.com/Starry-cz/autodl-assistant/releases/download/v1.0.2/autodl-assistant-setup.cmd)：下载后双击，默认安装到 `%LOCALAPPDATA%\AutoDL-Assistant`，安装成功后新建桌面 **AutoDL助手** 快捷方式；已有同名快捷方式会保留。
- [完整源码 ZIP](https://github.com/Starry-cz/autodl-assistant/releases/download/v1.0.2/autodl-assistant-v1.0.2.zip)：全部解压，进入含 `package.json`、`public`、`src`、`scripts` 的文件夹，双击 **安装并启动.cmd**。以后使用 **启动抢卡助手.cmd**。

也可按 Win + R，输入 `powershell`，依次执行这两条命令：

```powershell
Invoke-WebRequest -UseBasicParsing -Uri "https://raw.githubusercontent.com/Starry-cz/autodl-assistant/v1.0.2/install.ps1" -OutFile "$env:TEMP\install-autodl.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-autodl.ps1"
```

网页版无需提前安装 Node.js、npm 或 Git。需要时会下载 Node.js 22.23.4 到项目 `.tools`，安装依赖并准备浏览器，不修改系统 PATH。首次准备需要能访问 GitHub、nodejs.org、npm 和浏览器下载服务。默认网页地址为 [http://127.0.0.1:8787](http://127.0.0.1:8787)。

关闭网页不会停止后台。要停止网页版，请双击其项目目录中的 **停止抢卡助手.cmd**。旧网页版数据仍保存在该项目的 `.runtime` 中。

## 遇到问题

- **桌面程序已打开却找不到窗口**：查看任务栏右侧系统托盘，打开助手菜单并显示窗口。
- **登录失效或需要验证码**：进入账号页重新打开登录窗口，在 AutoDL 官网完成验证。
- **下载或启动失败**：确认下载的是对应版本的完整安装包或便携包，记录完整报错。不要只复制 EXE，也不需要关闭系统防护。
- **网页版提示端口被另一目录占用**：先到原项目目录运行停止脚本，再启动当前目录。桌面版不需要使用网页版的固定地址。

更多步骤见 [安装与使用说明](安装与使用说明.md)，版本记录见 [更新日志](CHANGELOG.md)。本项目为独立工具，与 AutoDL 官方无隶属关系。

## 开发

普通使用无需执行以下命令。开发时请准备 Node.js 22.12+（含 npm），在项目目录运行：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run check
npm.cmd run test:workspace-ui
```

桌面开发使用 `npm.cmd run desktop:dev`；Windows x64 打包使用 `npm.cmd run desktop:build`，产物位于 `output/desktop`。从源码准备与构建需要联网下载依赖及配套浏览器；分发给用户的完整桌面包已包含这些环境。
